Deine Daten

Die App speichert Wörter und Lernfortschritt lokal in diesem Browser. Kein Konto und kein Server nötig. Exportiere regelmäßig eine Sicherung.

Excel (.xlsx/.xls), JSON oder CSV/TXT importieren. Bei Excel wird das erste Tabellenblatt gelesen. Die Datei wird lokal im Browser verarbeitet; importierte Duplikate werden übersprungen.

So lernst du effektiv

  • Übe täglich 5–10 Minuten.
  • Versuche die Antwort zuerst selbst abzurufen.
  • Markiere „Gewusst“ nur, wenn du die Antwort ohne Hilfe wusstest.
  • Wiederhole schwierige Wörter öfter.
  • Nutze „Schreiben“, um die Wörter aktiv zu produzieren.
